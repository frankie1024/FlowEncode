What it is

A GUI for repeatable encoding workflows

FlowEncode is built for users who want a graphical Windows video encoding GUI without giving up the flexibility of command-line encoders, VapourSynth scripts and Av1an automation. It organizes input/output paths, encoder parameters, dependency state, queued jobs and logs into one desktop workflow.

Features

Core encoding modules

VapourSynth workspace

Embedded .vpy and .py editor with chained completion, diagnostics with Quick Fixes, smart filter insertion, and benchmarking. The preview window adds multi-output comparison, auto-crop, auto frame alignment, 9 preview filters, scopes, worst-frame scanning, and comparison-basket export.

Video encoding queue

Configure x264, x265, and SVT-AV1 tasks with input/output paths, encoder parameters, command previews, live logs, and post-queue actions.

Audio transcode & demux

Process audio with deew 5.7.0 (with licensed DEE), eac3to, FFmpeg, and opusenc, plus Blu-ray demuxing via DGDemux and Blu-ray/MKV track and chapter extraction via eac3to.

Av1an target quality

Run Av1an target-quality workflows with VMAF, SSIMULACRA2, XPSNR, and other backend-supported metrics, plus probe controls, parallelism, and extra encoder arguments.

Templates & environment guide

Save, import, export, and pin .profile templates; check, install, or update supported public tools, import extracted tool folders, and register tools to system PATH.

Local-first with MCP

Runs locally by default without actively uploading source files, outputs, templates, or local paths. Includes an opt-in local stdio MCP server sharing the desktop task queue.
